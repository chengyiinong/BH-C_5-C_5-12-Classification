# BH-C_5-C_5-12-Classification

- Lemma5.10_Case3.py is a SAT-based exhaustive verification of Case 3 from Lemma 5.10, which completes the classification of group-invariant Butson Hadamard matrices BH(C₅×C₅, 12).

- Result.txt contains a sample output of Lemma5.10_Case3.py from a test run.
